# Cadence Course Platform

Shared domain language for the course platform, used consistently in the user experience, code, and team discussions.

## Language

**Refund**:
A return of money paid for a course purchase. Refund is the canonical name for the feature through which learners request that return.
_Avoid_: Cancellation, cancel my purchase, reversal, chargeback when referring to this feature.

**Refund request**:
A learner's request for a refund, subject to review and approval. A pending refund request is awaiting a decision and does not mean money has been returned.
_Avoid_: Cancellation request, reversal request, pending chargeback.
